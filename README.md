### Application Security

Sécurisation d'API REST et de flux de paiement en production, avec une logique d'ingénieur plutôt que de simple implémentation fonctionnelle :

- Authentification et autorisation : JWT, OAuth2/OIDC, RBAC, gestion de sessions
- Sécurisation de paiement : prévention des doubles soumissions et des race conditions sur les webhooks Stripe
- Durcissement d'API : validation stricte des entrées, gating par rôle/plan, protection des uploads (type MIME, taille, scan)
- Référentiels appliqués : OWASP API Security Top 10, threat modeling STRIDE, méthodologie d'analyse de risque EBIOS RM
- Cloud security : modèle de responsabilité partagée AWS, gestion IAM, bases CloudTrail/GuardDuty
- Durcissement d'infrastructure : images Docker minimales, exécution non-root, gestion des secrets hors code source
- Revue de code orientée sécurité : SQL injection, XSS, exposition de données sensibles
